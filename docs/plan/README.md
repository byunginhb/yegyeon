## 핵심 루프 구현 상태

```
유저 유입 → 가입 → 본인인증 → 마켓 조회 → 예측 참여 → 결과 정산 → 재방문
   ✅         ✅      ❌ (미구현)    ✅           ✅            ✅          ❌ (출석보상 미구현)
```

**1차 출시 블로커:**
1. 본인인증 (전화번호 인증) 미구현
2. 출석 보상 미구현

## 빠른 현황

### 구현 완료
- 이메일/카카오/Google OAuth 인증
- Binary / Multiple Choice / Numeric 마켓 생성 및 예측
- LMSR 기반 확률 계산 + 마켓 정산
- 포인트 시스템 (지갑, 거래 내역)
- 댓글 / 신고 시스템
- 관리자 페이지 전체 (마켓 승인, 사용자 관리, 신고 처리)
- 마이페이지 / 랭킹 / 프로필
- 마켓 자동 마감 Cron

### 미구현 (P0)
- 본인인증 (전화번호 SMS 인증) — 정식 출시 전 필요, 베타 기간 스킵 가능

### 미구현 (P1)
- 알림 시스템
- 실시간 확률 업데이트 (WebSocket)
- 팔로우 목록 UI
- 관련 마켓 추천 고도화

### 미구현 (P2 이후)
- 광고 리워드, 일반 유저 마켓 생성, 마켓 북마크
- 퀘스트 고도화 (주간/시즌), 리그 시스템
- 상점 / 코스메틱 / 프리미엄 구독
