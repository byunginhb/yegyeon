## 남은 작업

### P0 — 정식 출시 전 필수

| 작업 | 비고 |
|------|------|
| 본인인증 (전화번호 SMS) | 베타 기간 스킵 가능. 정식 출시 전 반드시 구현. Supabase Phone Auth 또는 SOLAPI 연동 필요 |
| 본인인증 완료 보너스 지급 | 위 항목 의존 |
| 미인증자 거래 제한 | 위 항목 의존 |
| 팔로우 목록 UI | DB / API는 있음. 프로필 페이지에 팔로워 / 팔로잉 탭 추가만 필요 |

### P1 — 정식 출시 직후 (리텐션 / 운영 안정화)

| 작업 | 비고 |
|------|------|
| 알림 시스템 | `notifications` 테이블 + Header 배지 + 드롭다운 |
| 실시간 확률 업데이트 | Supabase Realtime 구독. 현재 새로고침 시에만 갱신 |
| 관련 마켓 추천 고도화 | `RelatedQuestions` 컴포넌트 존재, 콘텐츠 없음. `GET /api/markets/related/[id]` 필요 |
| 태그 필터링 / 자동완성 | 태그 저장은 됨. 검색/필터/클릭 내비게이션 미구현 |
| 고급 검색 (전문 검색) | PostgreSQL full-text search 또는 외부 검색엔진 연동 |

### P2 — 서비스 안정화 후 고도화

| 작업 | 비고 |
|------|------|
| 일반 Verified 유저 마켓 생성 | 본인인증 + 활동 이력 조건 설계 필요 |
| 광고 리워드 | Google AdSense / 카카오 모먼트 연동 |
| 마켓 북마크 | `bookmarks` 테이블 + 토글 버튼 + 마이페이지 탭 |
| 랭킹 고도화 | 예측 정확도 / 수익률 / 카테고리별 전문가 랭킹 |
| PARTIAL 정산 | 복수 결과 부분 정산 로직 |
