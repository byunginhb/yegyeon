## P1 — 정식 출시 직후

리텐션과 운영 안정화에 기여하는 기능

### 알림 시스템

사용자가 관련 이벤트를 놓치지 않도록 하는 핵심 리텐션 장치.

**필요한 알림 유형:**
- 내가 참여한 마켓 결과 확정
- 내가 작성한 마켓에 댓글
- 내 마켓 승인 / 거절
- 팔로우한 사용자의 새 마켓

**구현 방향:**
- `notifications` 테이블 추가
- `GET /api/notifications` — 알림 목록 (읽음 상태 포함)
- `PATCH /api/notifications/[id]` — 읽음 처리
- Header의 종 아이콘 배지 (읽지 않은 알림 수)
- 알림 드롭다운 패널

---

### 실시간 확률 업데이트

베팅 시 다른 사용자의 화면에서도 확률이 변하는 모습을 보여줌.

**구현 방향:**
- Supabase Realtime (`markets` 테이블 구독)
- 마켓 상세 페이지 `yes_probability` 실시간 반영
- BettingPanel 확률 표시 실시간 갱신

**현재 상황:** 페이지 새로고침 시에만 갱신됨

---

### 팔로우 목록 UI

팔로우 관계는 DB에 구현되어 있으나 조회 페이지가 없음.

**필요한 작업:**
- `GET /api/profile/[username]/followers` — 팔로워 목록
- `GET /api/profile/[username]/following` — 팔로잉 목록
- 프로필 페이지에 팔로워/팔로잉 탭 또는 모달 추가

---

### 마켓 공유 기능

SNS로 마켓을 공유하여 신규 유입 유도.

**구현 방향:**
- 마켓 상세 페이지 공유 버튼
- 카카오톡 공유 SDK 연동
- OG 메타태그 최적화 (`opengraph-image` 동적 생성)
- X(트위터), URL 복사 지원

---

### 관련 마켓 추천

현재 `RelatedQuestions` 컴포넌트가 있으나 콘텐츠가 없음.

**구현 방향:**
- 같은 카테고리 + 태그 기반 관련 마켓 조회
- 마켓 상세 페이지 우측 사이드바에 표시
- `GET /api/markets/related/[id]` API 추가

---

### 태그 필터링

현재 태그 저장은 구현되어 있으나 검색/필터에 활용되지 않음.

**구현 방향:**
- 마켓 생성 시 태그 자동완성 (기존 태그 추천)
- 마켓 목록 태그 필터 추가
- 마켓 상세 페이지 태그 클릭 → 해당 태그 목록으로 이동

## P2 — 서비스 안정화 후 고도화

서비스 방문 패턴이 확인된 뒤 추가

### 일반 Verified 유저 마켓 생성

현재: 운영자 또는 승인된 사용자만 마켓 생성 가능  
목표: 본인인증 + 활동 이력이 있는 일반 유저도 마켓 생성 가능

**조건 설계 예시:**
- 본인인증 완료
- 가입 후 N일 경과
- 최소 M포인트 이상 보유
- 생성 비용 차감 (스팸 방지)

---

### 광고 리워드

광고 시청 시 포인트 지급.

**구현 방향:**
- Google AdSense 또는 카카오 모먼트 연동
- 하루 최대 시청 횟수 제한
- 포인트 지급 `point_transactions` 기록 (타입: `ad_reward`)

---

### 마켓 북마크

관심 마켓을 저장하는 기능.

**구현 방향:**
- `bookmarks` 테이블 (user_id, market_id)
- 마켓 카드 / 상세 페이지 북마크 토글 버튼
- 마이페이지 북마크 탭

---

### 랭킹 고도화

현재 단순 포인트 랭킹 → 다차원 랭킹으로 발전

**추가 지표:**
- 예측 정확도 (calibration score)
- 수익률 랭킹
- 참여 마켓 수
- 카테고리별 전문가 랭킹

---

## P3 — 장기 고도화

초기 출시와 무관한 고급 기능

### 퀘스트 시스템

| 퀘스트 유형 | 예시 |
|-------------|------|
| 일일 퀘스트 | 오늘 베팅 1회, 댓글 1개 작성 |
| 주간 퀘스트 | 이번 주 3개 마켓 참여 |
| 시즌 퀘스트 | 이번 시즌 누적 수익 1,000포인트 |

---

### 시즌 리그

- 월 단위 시즌 운영
- 등급: 브론즈 → 실버 → 골드 → 플래티넘 → 다이아 → 마스터
- 시즌 종료 시 등급별 보상 지급

---

### 상점 / 코스메틱

- 아바타 프레임, 칭호, 프로필 테마
- 포인트 또는 실결제 (법률 검토 후)
- 한정판 아이템

---

### 프리미엄 구독

- Plus / Pro / Premium 3단계
- 퀘스트 보상 배수, 마켓 생성 한도 증가, 추가 통계 기능

---

### 매도 기능

현재 매수(베팅)만 지원. 매도는 P3.

- 보유 지분을 현재 확률로 되팔기
- 손실 최소화 전략 지원

---

### 공개 API

- 마켓 데이터 조회 API 공개
- API Key 발급 / 관리
- Rate limiting
- 문서화 (Swagger / Redoc)
