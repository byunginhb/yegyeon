## 잔여 P0 항목

### 1. 출석 보상 (일일 로그인 보너스)

**명세 근거:** `docs/project.md` 1차 출시 범위 — "출석 보상"

**현재 상태:** 미구현 (테이블, RPC, UI 모두 없음)

**필요한 구현:**

#### DB
```sql
-- 출석 기록 테이블
CREATE TABLE attendance (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id uuid REFERENCES users(id),
  checked_at date NOT NULL DEFAULT CURRENT_DATE,
  streak_count int NOT NULL DEFAULT 1,
  points_earned int NOT NULL,
  UNIQUE(user_id, checked_at)
);
```

#### 로직
- 하루 1회 로그인 시 자동 또는 버튼 클릭으로 체크인
- 연속 접속일(streak)에 따라 보상 증가
  - 1일: 10포인트
  - 3일 연속: 30포인트
  - 7일 연속: 70포인트
  - 14일 연속: 150포인트
  - 30일 연속: 300포인트
- streak는 하루를 넘기면 리셋
- `point_transactions`에 `attendance_bonus` 타입으로 기록

#### API
- `POST /api/attendance` — 오늘 출석 체크 (중복 방지)
- `GET /api/attendance` — 내 출석 현황 (streak, 마지막 체크인)

#### UI
- 홈 또는 마이페이지에 출석 체크 버튼 / 스트릭 표시
- 이미 체크인한 날은 "내일 다시 오세요" 표시
- 연속 접속일 배지 표시 (7일, 30일 등)

### 2. 본인인증 (전화번호 SMS 인증)

**명세 근거:** `docs/project.md` — "본인인증 완료 전에는 거래, 마켓 생성, 랭킹 반영 제한"

**현재 상태:** 미구현

**중요도 재검토 필요:**
> 현재 서비스가 베타 테스트 단계이고, Supabase Phone Auth 설정이 별도로 필요하므로 **베타 기간 동안은 스킵 가능**. 단, 정식 오픈 전에는 반드시 구현 필요.

**구현 시 고려사항:**
- Supabase Phone Auth 또는 외부 SMS API (알리고, SOLAPI 등) 사용
- 1인 1계정 보장을 위한 전화번호 유니크 제약
- 본인인증 완료 시 보너스 포인트 지급
- 만 14세 미만 제한 정책 (법적 요구사항)
- `users` 테이블에 `phone_verified boolean` 컬럼 추가 필요

**베타 기간 임시 처리:**
- 현재 모든 가입자가 거래 가능 상태 (제한 없음)
- 정식 오픈 전 구현 예정으로 표시
