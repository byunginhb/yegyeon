# 테슬라 호구연대표 — 원페이지 웹서비스 축소 기획안

## 코딩 GPT / 개발자에게 전달할 요청

한국에 출시된 테슬라를 **연식·트림별로 가볍게 비교하는 한 페이지짜리 정적 웹서비스**를 만들어 주세요.

거창한 플랫폼이 아니라, 연식과 트림을 나란히 세워 놓고 “이 시기에 무엇이 달랐는지”, “국내에 얼마나 많이 출고됐는지”, “지금 기준으로 얼마나 호구였는지”를 재미있게 보는 페이지입니다.

## 한 줄 정의

**한국 출시 Tesla의 연식·트림별 차이, 등록대수 분포, 기본 호구지수와 관련 영상을 한 화면에 보여주는 독립형 정적 페이지.**

## 화면 구성

### 1. 상단 소개와 필터

- 서비스명: `테슬라 호구연대표`
- 필터: 모델, 연식, 트림, 생산국
- 기본 대상은 판매량이 많은 `Model 3`와 `Model Y`
- Model S, Model X, Cybertruck은 보조 항목으로 표시 가능

### 2. 연식·트림 카드 나열

연도 순서대로 차량 카드를 가로 또는 그리드로 나열합니다.

각 카드에는 아래 정보만 간단히 표시합니다.

- 연식, 모델, 트림
- 미국산/중국산과 생산공장
- 배터리 제조사·화학계
- HW3/HW4, 카메라, USS·레이더
- 통풍시트, 뒷좌석 화면, 방향지시등 레버, 히트펌프
- 국내 FSD 상태
- 당시 대표 판매가와 보조금 구간
- 해당 연도의 국내 신규등록대수
- 기본 호구점수와 짧은 한 줄 평가

### 3. 출고량 분포 그래프

- 실제 국내 신규등록대수를 연도별로 보여줍니다.
- 막대그래프 위에 부드러운 분포 곡선을 겹쳐 “표준분포 느낌”을 냅니다.
- 실제 데이터를 억지로 정규분포에 맞추지는 않습니다.
- 트림별 대수가 공식적으로 확인된 경우만 세분화합니다.
- 트림별 대수가 없는 연도는 모델 전체 대수를 보여주고 `트림별 대수 미확인`이라고 표시합니다.
- 사용자가 카드를 누르면 해당 연도·모델·트림이 그래프에서 강조됩니다.

### 4. 클릭 상세 패널

카드를 클릭하면 같은 페이지 안에서 상세 패널을 엽니다.

- 기본 호구점수와 등급
- 점수가 올라간 이유 3개
- 장점 또는 감점 상쇄 요소
- 직전 세대와 달라진 점
- 다음 세대에서 개선된 점
- 판매가·보조금·FSD·배터리·편의사양 요약
- 데이터 신뢰도: `verified`, `mixed`, `unknown`

개인 구매가격을 입력받는 계산기는 이번 버전에서 제외합니다. 점수는 해당 연식·트림의 **세대 기준 기본점수**입니다.

## 기본 호구점수

총 100점으로 단순하게 운영합니다.

- 가격·출고 타이밍: 35점
- FSD 구매권리와 현재 사용 가능 여부: 20점
- 배터리·BMS_a079 위험: 20점
- HW·카메라·편의사양 세대: 15점
- 보증·교체·수리 위험: 10점

등급은 다음과 같습니다.

- 0~19: 타이밍의 신
- 20~34: 평범한 테슬람
- 35~49: 약호구
- 50~64: 호구
- 65~79: 흑우
- 80~100: 테슬라 발전기금 명예이사

점수는 사실 판정이 아니라 재미를 위한 편집값이므로 화면에 `밈·비교용 점수`라고 표시합니다.

## 하단 콘텐츠

### YouTube 영상

- 로컬 JSON에 저장된 기본 영상 2~4개를 iframe으로 임베딩합니다.
- 화면에 YouTube URL 입력창 하나를 둡니다.
- URL을 붙여 넣으면 같은 페이지에서 즉시 임베딩합니다.
- 별도 저장 서버는 사용하지 않습니다.
- 필요하면 브라우저 `localStorage`에 최근 입력 URL만 저장합니다.
- 영상 제목, 채널명, 원문 링크를 같이 표시합니다.

## 데이터 운영 원칙

- 관리자 페이지, 서버, 데이터베이스, 크롤러, 외부 API를 사용하지 않습니다.
- 모든 내용은 `tesla_hogu_local_data.json` 한 파일에서 읽습니다.
- 데이터에는 반드시 `sourceUrl`, `confidence`, `note`를 둘 수 있게 합니다.
- 확인되지 않은 트림별 출고량을 임의로 나누지 않습니다.
- 생산월에 따라 사양이 섞이는 경우 `MIX`로 표시합니다.
- 연식만으로 배터리·카메라·MCU를 확정하지 않고 VIN·생산월 확인 문구를 노출합니다.

## 완료 기준

- 한 화면에서 연식·트림 카드를 탐색할 수 있다.
- 카드 클릭 시 기본 호구점수와 세대 차이가 나타난다.
- 연도별 실제 등록대수 분포가 시각화된다.
- 트림 대수가 없을 때 임의 추정값을 사실처럼 표시하지 않는다.
- YouTube URL을 붙여 넣어 임베딩할 수 있다.
- 네트워크 연결이 없어도 기본 차량·판매량 데이터가 표시된다.
