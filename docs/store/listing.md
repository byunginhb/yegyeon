## 6. 콘텐츠 등급 설문 (IARC) 답안 가이드

가상 포인트로 결과를 맞히는 **모의 도박(simulated gambling)** 요소가 있으므로 정직하게 답한다. 실제 화폐·환전은 없다.

- 폭력: **없음**
- 성적 콘텐츠 / 노출: **없음**
- 비속어 / 저속한 유머: **없음** (앱 자체 콘텐츠 기준. 사용자 댓글은 UGC 항목에서 처리)
- 약물·주류·담배: **없음**
- **모의 도박(simulated gambling): 예** — 가상 포인트로 미래 사건 결과에 예측(베팅)하는 예측 시장. 현금·현금 가치 상품 획득 불가
- 실제 현금 도박(real-money gambling): **아니오** — 현금 결제·환전·상금 없음
- 사용자 간 상호작용: **예** — 사용자가 마켓(질문)을 만들고 댓글을 작성하며, 다른 사용자가 이를 봄
- 사용자 생성 콘텐츠(UGC) 공유: **예** (마켓 제목·설명·이미지·댓글). 신고 기능(`components/common/ReportButton.tsx`)과 관리자 승인·숨김 절차 있음
- 개인정보(위치 등) 공유: **아니오**
- 디지털 상품 구매: **아니오** (인앱 결제 없음)
- 예상 등급: **만 12세 이상 또는 만 16세 이상** (모의 도박 항목으로 IARC가 자동 산정. 국가별로 다를 수 있음)

> 콘솔 "앱 콘텐츠 > 앱 액세스"에는 로그인 없이도 마켓 열람이 가능함을, 필요 시 심사용 테스트 계정(이메일 로그인)을 등록.
> "앱 콘텐츠 > 도박·게임" 신고 항목: 실제 돈 도박 앱 **아니오**. 상금 없는 모의 도박이므로 도박 라이선스 불필요.
