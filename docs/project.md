## 개발 우선순위 반영본

Manifold Markets를 분석하여 한국형 예측 배팅 플랫폼 “예견”의 정책 구조를 설계하였습니다.

다만 모든 기능을 1차 범위에 포함할 경우 개발 공수가 과도하게 증가할 수 있으므로, 본 문서는 **기능별 우선순위를 반영한 단계적 개발 기준**으로 재정리하였습니다.

---

# 1. 서비스 개발 원칙

예견은 플레이머니 기반 예측 마켓 플랫폼입니다.

그러나 1차 출시의 목표는 “모든 예측시장 기능을 완성하는 것”이 아니라, 아래의 **핵심 루프가 실제로 동작하는지 검증하는 것**입니다.

**핵심 루프**

유저 유입 → 가입 → 본인인증 → 마켓 조회 → 예측 참여 → 결과 정산 → 재방문

따라서 1차에서는 다음 기준을 적용합니다.

### 1차 개발 원칙

- 거래 시스템은 단순하게 시작한다
- 마켓 유형은 최소화한다
- 정산 유형은 단순화한다
- 운영자가 통제 가능한 범위로 생성권을 제한한다
- 리텐션과 수익화 기능은 핵심 루프 검증 이후 순차 추가한다

# 2. 우선순위 체계

## P0

없으면 예견 서비스가 성립하지 않는 기능

1차 출시 필수 기능

## P1

1차 오픈 직후 빠르게 붙이면 좋은 기능

리텐션과 운영 안정화에 도움되는 기능

## P2

서비스가 돌아간 뒤 추가하는 고도화 기능

리텐션 강화, 수익화 강화, 커뮤니티 확장 기능

## P3

장기 검토 기능

초기 출시와 무관한 기능

## 1. Manifold Markets 핵심 구조 분석

Manifold는 플레이머니(Mana) 기반의 소셜 예측 마켓 플랫폼입니다. 분석 결과 다음과 같은 핵심 구조로 운영됩니다.

**플랫폼 핵심 메커니즘:** 유저가 직접 예측 질문(마켓)을 생성하고, 다른 유저들이 Yes/No 또는 다지선다 형태로 배팅합니다. 확률은 자동화된 마켓메이커(AMM)와 지정가 주문(Limit Order)의 조합으로 실시간 결정됩니다. 마켓 생성자가 결과를 판정(Resolve)하며, 맞춘 유저에게 보상이 돌아가는 구조입니다.

**수익 모델:** 플레이머니 판매, 멤버십 구독, 코스메틱 아이템 판매의 3축 구조를 가지고 있습니다. Mana 구매($5→Ṁ500, $25→Ṁ2,500, $100→Ṁ11,000, $1,000→Ṁ120,000), 멤버십 구독(Plus Ṁ500/월, Pro Ṁ2,500/월, Premium Ṁ10,000/월), 코스메틱 아이템 판매(모자, 아바타, 호버카드 등)의 3축으로 구성됩니다.

**리텐션 시스템:** 일일 예측 스트릭(연속 접속 보상 Ṁ5~25), 시즌제 리그(Bronze~Masters 6등급, 월 단위), 주간 퀘스트, 리퍼럴 보상(친구 초대 시 Ṁ1,000), 대출(Loan) 시스템 등을 운영합니다.

### 예견에 적용하는 해석

예견은 Manifold의 운영 구조를 참고하되, **1차에서는 핵심 루프만 우선 개발**하고, 스트릭·리그·퀘스트·대출·고급 수익화 구조는 후속 단계로 이관합니다.

## 2. "예견" 플랫폼 전 과정 정책 설계

### 📌 PHASE 1: 고객 유입 정책 (Acquisition) **1차 우선순위: P0**

### 1) 가입 방식

- 카카오, 네이버, 구글, 애플 로그인 지원
- 이메일/ID 기반 가입도 허용
- 가입 즉시 계정 생성 가능
- **본인인증 완료 전에는 거래, 마켓 생성, 랭킹 반영 제한**

### 2) 초기 보상

- 모든 신규 가입자에게 플레이머니 기본 잔고 지급
- 톡표권은 현금 가치가 없고 환전 불가
- 추천인 보상, 출석 보상, 기여 보상 제공

### 3) 본인인증 정책

- 거래, 리그, 칭호, 생성자 권한은 본인인증 후 활성화
- 본인인증 완료 시 1회성 보너스 제공
- 만 14세 미만은 법정대리인 동의 또는 가입 제한 정책 적용

**온보딩 설계:** 카카오/네이버/구글 소셜 로그인 원클릭 가입으로 진입장벽을 최소화합니다. 가입 즉시 "예견 코인(가칭)" 1,000개를 무료 지급하여 바로 참여를 유도합니다. Manifold는 13세 이상을 대상으로 하는데, 한국법(게임산업진흥법, 사행성 규제)을 감안하면 14세 이상 또는 18세 이상으로 설정하되, 법률 검토가 필수입니다.

**유입 채널 전략:** 첫째, 리퍼럴 프로그램으로 추천인과 피추천인 모두에게 코인을 지급합니다(Manifold는 추천 시 Ṁ1,000 지급, QR코드·고유링크 방식). 둘째, 시사·이슈 연동으로 "이번 주 K-리그 우승팀은?", "다음 대선 지지율 1위는?" 같은 시의성 있는 마켓을 SNS에 공유합니다. 셋째, 크리에이터/인플루언서와 협업하여 전용 예측 마켓을 생성하게 하고, 해당 팔로워를 유입시킵니다.

**핸드폰 인증 보너스:** Manifold처럼 본인인증 완료 시 1회성 대량 코인 보너스를 제공하여 다중 계정 방지와 유입을 동시에 달성합니다.

---

### 📌 PHASE 2: 마켓(예측 질문) 생성 정책 **1차 우선순위: P0**

### 1) 마켓 유형

- 이진형 Yes/No
- 다지선다형
- 숫자 예측형
- 설문형 Poll
- 필요 시 바운티형 답변형 질문 추가 가능

Manifold 공식 FAQ도 이 5가지를 지원한다고 안내합니다.

### 2) 생성 조건

- 본인인증 필수
- 최소 레벨 또는 최소 활동 이력 필요
- 생성 비용 부과
- 설명, 해결 기준, 마감일, 카테고리 입력 필수

### 3) 생성 가이드라인

- 해결 기준이 명확해야 함
- 외부 출처 링크가 가능하면 포함
- 설명이 모호한 경우 생성 제한
- 선거, 개인정보, 범죄 의혹, 실명 훼손형 질문은 별도 제한

**마켓 유형:** Manifold 분석 결과 4가지 핵심 유형이 확인됩니다. "예견"도 이를 한국화하여 적용합니다. Yes/No(이진) 마켓은 "삼성이 올해 반도체 1위를 유지할까?" 같은 단순 예/아니오 질문입니다. 다지선다 마켓은 "다음 시즌 K-리그 우승팀은?" 같이 여러 선택지가 있는 유형입니다. 숫자 예측 마켓은 "올해 코스피 최고점은 몇 포인트?" 같은 수치 예측입니다. 투표/설문은 배팅 없이 의견만 수집하는 가벼운 유형입니다.

**마켓 생성 비용:** Manifold는 마켓 생성 시 최소 Ṁ100의 유동성 풀을 제공해야 합니다. "예견"도 생성 비용을 부과하여 스팸 마켓 방지와 마켓 품질 유지를 달성합니다. 유동성이 클수록(Ṁ100 → Ṁ1,000 → Ṁ10,000 → Ṁ100,000) 더 많은 트레이더를 유치할 수 있고, 고유 트레이더당 보상(Manifold: Ṁ3/트레이더)이 지급됩니다.

**마켓 생성 가이드라인:** 명확한 판정 기준 필수 기재, 판정 예정일 설정, 관련 토픽/카테고리 태그 부착, AI 자동 설명 생성 기능(Manifold의 "Generate with AI" 참조), 공개/비공개 설정 옵션을 포함합니다.

**카테고리 체계:** Manifold의 토픽 시스템을 참고하여 정치, 기술, 스포츠, 문화, 경제, 재미, 글로벌 등 기본 카테고리를 설정하고 한국 특화 카테고리(K-POP, 수능, 부동산, K-리그, 한국정치 등)를 추가합니다.

### 📌 PHASE 3: 트레이딩(배팅) 정책 **1차 우선순위: P0**

### 1) 거래 메커니즘

- AMM + 지정가 주문 하이브리드 구조
- 확률은 시장 가격으로 표현
- 배팅 시 유저는 결과 지분을 구매
- 정답 지분은 정산 시 1주당 1포인트 가치

Manifold FAQ도 가격은 **limit order와 AMM 조합**으로 결정된다고 설명합니다.

### 2) 유동성 정책

- 생성 비용은 기본 유동성으로 사용
- 유저는 추가 유동성 공급 가능
- 유동성 제공자는 일부 회수 가능하지만 손실 가능성 존재
- 운영 측은 유동성 공급 위험을 명확히 고지

Manifold는 **초기 비용 전부가 유동성으로 들어가며**, 공급자는 일부 회수 가능하지만 손실을 기대해야 한다고 명시합니다.

### 3) 대출/레버리지

- 출시 초기에는 비활성화 권장
- 서비스 안정화 후 프리미엄 사용자 대상 실험적 도입 검토
- 한국 법·운영 리스크가 커서 MVP 범위에서는 제외 권장

Manifold는 대출 기능을 제공하지만, 이는 고급 기능이므로 예견 초기에 바로 넣을 필요는 없습니다.

**핵심 메커니즘:** Manifold는 AMM(자동화 마켓메이커) + Limit Order(지정가 주문) 하이브리드 시스템을 사용합니다. 트레이더가 배팅하면 주식처럼 "지분(shares)"을 구매하고, 확률이 실시간으로 변동합니다. 맞은 지분은 1개당 1코인의 가치를 갖게 됩니다.

**유동성 풀 정책:** 유동성이 클수록 확률 변동이 안정적이고, 대규모 배팅에도 가격 왜곡이 적습니다. 누구나 기존 마켓에 유동성을 추가할 수 있으며, 마켓 해결 시 잔여 유동성의 일부를 회수할 수 있습니다(단, 확률 변동 폭에 따라 손실 가능).

**대출(Loan) 시스템:** Manifold의 고급 기능으로, 기존 포지션을 담보로 추가 자금을 빌릴 수 있습니다. Free 유저는 일일 무이자 대출(포지션의 1%), Pro는 일 0.03% 이자의 마진 대출도 가능합니다. 최대 레버리지는 Free 2배, Plus 2배, Pro 3배, Premium 4배입니다. "예견"에서는 초기에는 단순화하고, 성숙기에 도입을 검토합니다.

---

### 📌 PHASE 4: 판정(Resolution) 정책 **1차 우선순위: P0**

### 1) 기본 원칙

- 마켓 생성자가 정산
- 운영진은 분쟁, 방치, 오정산, 기술 오류 시 개입 가능

Manifold도 creator resolve를 원칙으로 하고, 예외적으로 운영진이 뒤집을 수 있다고 밝힙니다.

### 2) 정산 유형

- YES
- NO
- PARTIAL
- N/A

### 3) N/A 정책

- 거래자 원금 반환
- 유동성 제공자 원금 반환
- opportunity cost 발생 가능성 고지
- 남용 시 제재

Manifold는 N/A 시 거래자와 유동성 제공자에게 자금이 반환되며, 남용을 경고합니다.

### 4) 정산 기한

- 조건 충족 후 즉시 정산 권장
- 일정 기간 미정산 시 유저 신고 가능
- 신고 후 운영진 심사 및 대리 정산 가능

**판정 주체:** Manifold는 마켓 생성자에게 판정 권한을 부여합니다. "예견"도 기본적으로 생성자 판정을 원칙으로 하되, 모더레이터 개입 장치를 마련합니다.

**판정 유형:** YES 판정(Yes 지분 보유자에게 배당), NO 판정(No 지분 보유자에게 배당), PARTIAL 판정(특정 확률로 비례 배분), N/A 판정(마켓 취소, 전액 환불 — 단 이 기간 동안의 기회비용은 발생)이 있습니다.

**판정 기한 정책:** 판정 조건 충족 후 즉시 판정을 권장합니다. Manifold는 타 유저가 댓글로 판정을 요청한 후 10일이 지나면 관리자가 대신 판정할 수 있습니다. "예견"도 유사한 시한을 두어 방치 마켓을 방지합니다.

**판정 분쟁 처리:** 사기성 판정(의도적으로 잘못 판정하여 이득을 취하는 행위)은 관리자가 N/A로 재판정하고 제재합니다. 부정확한 판정은 생성자에게 경고 배지를 부착합니다. 이의제기 프로세스를 마련하여 증거 제출 → 모더레이터 검토 → 재판정 여부 결정의 절차를 운영합니다.

### 📌 PHASE 5: 리텐션 & 게이미피케이션 정책 **1차 우선순위: P1**

### 1) 스트릭

- 하루 1회 이상 참여 시 연속 보상
- 보상은 단계적으로 증가

- 선거일 전 6일간은 당선인 예상, 지지도, 모의투표형 결과 노출·거래 중단 권장
- 법률 자문 후 선거 카테고리 범위 확정

이 부분은 "예견" 성공의 가장 중요한 허들입니다.

**사행성 규제 리스크:** 한국에서 예측 시장은 사행행위 등 규제 및 처벌 특례법과 충돌할 수 있습니다. Manifold가 "플레이머니(현금 환전 불가)"를 강조하는 이유가 바로 이것입니다. "예견"도 반드시 플레이머니 모델을 채택하고, 환전 가능성을 완전히 차단해야 합니다. 외부에서의 RMT(Real Money Trading)도 이용약관에서 명시적으로 금지해야 합니다.

**게임산업진흥법:** 유료 아이템(코인 구매)이 포함되면 게임물관리위원회 등급분류를 받아야 할 수 있습니다. "예측 플랫폼"이 "게임"으로 분류되는지 법적 판단이 필요합니다.

**개인정보보호법:** 한국 개인정보보호법(PIPA) 및 정보통신망법에 따른 개인정보 수집·이용 동의, 만 14세 미만 법정대리인 동의 등을 반드시 준수해야 합니다.

**선거법:** 선거 관련 마켓은 공직선거법상 여론조사 규정과 충돌할 수 있으므로, 선거 마켓의 운영 범위에 대해 법률 검토가 필수적입니다.
